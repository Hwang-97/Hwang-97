## About

Spring Boot와 Vue.js를 중심으로 웹 서비스를 개발하고, 서버 구성부터 Docker 기반 배포 환경까지 구축해 왔습니다.
기능 구현 이후의 안정적인 운영을 중요하게 생각하며, AI를 실제 서비스에 연결하는 방법도 탐구합니다.

- **웹 서비스 개발** — 연구 데이터 플랫폼의 백엔드·프론트엔드 개발과 고객 요구사항 반영
- **인프라와 운영** — 서버·네트워크 구성, CI/CD 구축, 모니터링 및 장애 대응 자동화
- **AI 서비스** — RAG 기반 검색·추천, 대화 이력을 활용한 멀티턴 챗봇 개발 경험
